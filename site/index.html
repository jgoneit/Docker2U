릴리스 노트Release notes ↗

Docker도 함께 설치되나요?Does it install Docker?

아니요. Docker CLI와 실행 중인 로컬 Linux Engine이 별도로 필요합니다. Compose 기능에는 Docker Compose 플러그인도 필요합니다. 앱은 전역 context를 바꾸거나 런타임을 시작하지 않습니다. CLI context를 변경했다면 Reconnect를 눌러 새 Engine에 연결하세요.No. Docker CLI and a running local Linux Engine are required separately. Compose features also need the Docker Compose plugin. The app does not change the global context or start the runtime. Use Reconnect after changing the CLI context to select the new Engine.

어떤 환경을 지원하나요?Which platforms are supported?

macOS 14 이상인 Apple Silicon Mac과 로컬 Unix socket의 Linux Engine을 지원합니다. Windows·Intel Mac·원격 TCP/SSH endpoint는 지원하지 않습니다.Apple Silicon Macs running macOS 14 or later, with a Linux Engine on a local Unix socket. Windows, Intel Macs, and remote TCP/SSH endpoints are not supported.

처음 실행할 때 macOS 경고가 보여요.Why does macOS warn on first launch?

현재 알파는 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 출처와 체크섬을 확인한 뒤 설치 안내의 앱별 허용 절차를 참고하세요. 조직 정책상 설치가 제한될 수 있습니다. 시스템 전체 보안 설정을 끌 필요는 없습니다.This alpha is ad-hoc signed and not notarized by Apple. Verify its source and checksum, then see the app-specific first-launch steps in the installation guide. Organization policies may restrict installation. Do not disable system-wide security settings.

로그와 이력은 계속 저장되나요?Are logs and history saved permanently?

기록은 앱 세션의 제한된 메모리에만 보관합니다. 앱 종료·Engine 재연결 시 초기화되며, 수집하지 못한 구간은 복원하지 않습니다. 영구 저장이나 모니터링 알림 서비스는 제공하지 않습니다. 보관 범위 자세히 보기Records use bounded session memory and are cleared on quit or Engine reconnect. Missing collection intervals are not reconstructed. There is no persistent history or monitoring alert service. Read the retention limits (Korean)

터미널 연결을 끊으면 명령도 종료되나요?Does disconnecting stop a command?

연결 끊기는 명령의 종료를 보장하지 않습니다. 셸에서 Ctrl+C나 exit로 중단·종료하세요. 터미널은 컨테이너의 실제 사용자·네트워크·마운트 권한으로 실행됩니다. 최대 8개 세션과 세션당 2,000줄을 보관합니다.Disconnecting does not guarantee a command has stopped. Interrupt or exit inside the shell using Ctrl+C or exit. Commands use the container’s actual user, network, and mount permissions. Up to 8 sessions and 2,000 scrollback lines per session are retained.

어떻게 업데이트하나요?How do I update?

자동 업데이트는 아직 없습니다. 새 DMG를 받은 뒤 앱을 종료하고 Applications의 앱을 교체하세요. 종료 시 로그·이력·터미널 세션은 초기화됩니다.There is no automatic updater yet. Download the new DMG, quit the app, and replace it in Applications. Quitting clears logs, history, and terminal sessions.

조작에 앞서 무엇을 확인해야 하나요?What should I check before taking action?

Start·Stop·Restart와 Compose 작업은 실제 환경을 변경합니다. 대상과 작업 내용을 확인하세요. 명령 종료가 서비스의 준비 완료를 뜻하지 않으며, 실패·취소 시 적용된 변경을 자동으로 되돌리지 않습니다. 이미지 내보내기에는 볼륨 데이터와 실행 후 파일 변경이 포함되지 않습니다.Start, Stop, Restart, and Compose operations change your actual environment. Review targets and actions. Command completion is not service readiness; applied changes are not automatically rolled back on failure or cancellation. Image exports exclude volume data and container filesystem changes.
